Personal Expense & Budget Tracker

About the Project

Personal Expense & Budget Tracker is a web-based application developed using Python and Flask. It helps users manage daily expenses, track spending, and monitor monthly budgets.

Technologies Used

- Python
- Flask
- SQLite
- SQL
- HTML
- CSS

Features

- Add new expenses
- Delete expenses
- Categorize expenses
- Track total spending
- Set monthly budget limits
- Compare expenses with budgets
- View recent expenses

    └── index.html

Installation and Setup

1. Install Python.
2. Install Flask:
   "pip install flask"
3. Run the application:
   "python app.py"
4. Open your browser and visit:
   "http://127.0.0.1:5000"

Database

SQLite is used to store expense details and monthly budget information.
